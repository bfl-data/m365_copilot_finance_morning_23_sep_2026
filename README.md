# M365 Copilot — Finance Morning Session

**Bajaj Finance Limited | M365 Copilot Training**
Training delivered by **Technizer India**

This repository contains the participant materials and sample data for a hands-on Microsoft 365 Copilot training session for the Finance team at Bajaj Finance Limited.

## Contents

| File | Description |
|------|-------------|
| `Copilot_Participant_Guide.md` | Main participant hands-on guide — 5 live exercises using M365 Copilot Chat, built around the meta-prompt method. |
| `MetaPrompting_Guide.md` | Reference guide to meta-prompting — using Copilot to write better Copilot prompts, with ready-to-use Finance prompt templates. |
| `BFL_Finance_CopilotExcel_Participant_Guide.md` | Exercise guide for Copilot in Excel — formulas and pivot tables on finance operations data. |
| `Excel_To_PowerPoint.md` | 9-step workbook for turning a raw file into an analysis, a Word document, and a leadership-ready PowerPoint deck using Copilot. |
| `BFL_Finance_Copilot_Data.xlsx` | Sample dataset used in the participant guide — Financial Statements, Budget Analysis, Expense Analysis, Financial Reporting, and Financial Forecasting sheets. |
| `BFL_Finance_Copilot_Demo.xlsx` | Sample finance operations dataset (25 requests) used for the Copilot in Excel formula/pivot exercises. |

## How to Use This Repo

1. Start with `MetaPrompting_Guide.md` to understand the meta-prompt approach used throughout the session.
2. Follow `Copilot_Participant_Guide.md` for the core M365 Copilot Chat exercises, attaching `BFL_Finance_Copilot_Data.xlsx` as instructed.
3. Use `BFL_Finance_CopilotExcel_Participant_Guide.md` alongside `BFL_Finance_Copilot_Demo.xlsx` for the Copilot in Excel exercises.
4. Use `Excel_To_PowerPoint.md` to practice the end-to-end flow from a raw file to a leadership deck.

## Prerequisites

- Access to Microsoft 365 Copilot Chat
- Access to Copilot in Excel
- The sample Excel files from this repository (via OneDrive/SharePoint as directed by your trainer)
